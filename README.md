Public [Homebrew](https://brew.sh/) tap for TomTom's [XCMetrics](https://xcmetrics.io/) client (ttxcmetrics).

## TTXCMetrics
TTXCMetrics is a fork of Spotify's open source [XCMetrics](https://xcmetrics.io/) utility with some custom plugins to retrieve additional metadata from Xcode builds. The source code is available in the [tomtom-forks](https://github.com/tomtom-forks/XCMetrics) GitHub page.

## How to Use This Tap
You can source it with the following command:

```sh
brew tap tomtom-international/ttxcmetrics
```

Then, install TTXCMetrics by running:

```sh
brew install ttxcmetrics
```
